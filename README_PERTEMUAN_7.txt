PROJECT CARDO_MOON - PERTEMUAN 7

Perubahan yang diterapkan:
- BaseActivity menjadi halaman awal aplikasi.
- Bottom Navigation dengan menu Home, Message, dan More.
- Home menampilkan tombol untuk membuka aktivitas Pertemuan 2, 3, 4, 5, dan 7/Fragment.
- Package pertemuan_2 sampai pertemuan_6 dipindahkan ke dalam package Home sesuai materi.
- SixthActivity menampilkan SatuFragment secara default dan tombol untuk berpindah ke SatuFragment, DuaFragment, dan TigaFragment.
- Ditambahkan ikon vector untuk menu bottom navigation.
- Login sengaja dilewati sesuai materi (bypass halaman login sementara). Project ini tidak memiliki AuthActivity/SplashScreenActivity maupun username/password login.

Cara membuka:
1. Ekstrak ZIP.
2. Buka folder cardo_moon melalui Android Studio.
3. Tunggu Gradle Sync selesai.
4. Jalankan aplikasi pada emulator/perangkat.

Catatan: Project tidak menyertakan folder build/cache agar ZIP lebih ringan. Build ulang akan dilakukan oleh Android Studio.
